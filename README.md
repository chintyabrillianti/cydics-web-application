# CYDICS — Social Assistance Management System

**A web-based platform for managing social assistance, donations, and beneficiary eligibility.**

CYDICS ("Cinta Yatim Duafa" Indonesian Communities) is a Laravel-based application developed for Yayasan Al-Farisi Indonesia to streamline social assistance operations, improve donation transparency, and support data-driven beneficiary selection.

### Key Features

- **Role-Based Access Control** — Dedicated access for administrators, beneficiaries, and donors.
- **Application Management** — Beneficiary registration, document submission, verification, and application status tracking.
- **Donation Management** — Donation records, donation history, and transparency reports.
- **Administrative Dashboard** — Manage beneficiaries, programs, activities, annual reports, and website content.

### Tech Stack

`Laravel 13` · `PHP` · `MySQL` · `Blade` · `Bootstrap 5` · `JavaScript` · `Git` · `GitHub`

### What I Built

- Developed a multi-role web application using Laravel's MVC architecture.
- Implemented application workflows and role-based access control.
- Integrated database-driven features for donations, reporting, and beneficiary management.
- Implemented Decision Tree-based eligibility classification to support administrative decision-making.

### Getting Started

```bash
git clone https://github.com/chintyabrillianti/cydics-web-application.git
cd cydics-web-application
composer install
```

Copy `.env.example` to `.env`, configure your database credentials, then run:

```bash
php artisan key:generate
php artisan migrate
php artisan serve
```

**Note:** The application requires PHP, Composer, and a configured MySQL database. Seeders or additional setup may be required depending on the repository configuration.
